# Music catalogue artwork

On Repeat now uses live iTunes Search API metadata and validated Apple CDN artwork. The old predefined catalogue and downloaded sample covers have been removed. No audio, previews, lyrics or videos are retained. See [music integration documentation](../../../docs/music-search.md) for provenance, branding terms, limits and local persistence.

The separate public portfolio target uses predefined song information and bundled covers in `src/assets/demo/`, with ordinary Spotify links. “Je veux” by Greg Gontier uses the user-supplied Grégoire cover (`images-8.jpeg`, copied as `greg-gontier-gregoire.jpg`) and links directly to [the supplied Spotify track](https://open.spotify.com/track/5SKNuosJIUYtzmIj8nzQbu). Its artwork remains its owner’s property. The other covers are original sample illustrations; none are fetched from iTunes. The production catalogue above is preserved.
