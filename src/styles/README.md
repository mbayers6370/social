# Stylesheet conventions

`globals.css` owns Tailwind layers, base typography, native fields, focus, and global motion preferences. `application.css` is the single ordered feature-style manifest; it loads shared components before their consumers. `tokens.css` defines the palette, type scale, spacing, and shared layout geometry.

Each full selector has one owning stylesheet. Keep its responsive, interaction, and reduced-motion variants together. Feature-specific contextual selectors belong with that feature. Run `npm run styles:check` to catch repeated imports, orphan stylesheets, conflicting ownership, and repeated properties for the same selector in the same conditional context. Selector groups are expanded, so a later singleton cannot silently override its shared declaration. Keep one authoritative declaration; place intentional responsive, support, layer and interaction variants in their own contexts. This guard does not prove that different selectors or shorthand/longhand combinations cannot compete.

## Shared design rules

- Post body text uses Margin Aside Medium through `--font-post`, including the welcome feed example. Other body copy, forms, labels, and controls use Inter. Headings and the wordmark use Margin Aside. Section headings use title case, such as Recent Posts and Your Photographs; body copy remains in sentence case.
- Entry text and labels start at 1rem. Small notes share 0.75rem, 400-weight Inter, 1.5 line height, and `--note-foreground`.
- Use spacing tokens: related details 8px, groups 24px, sections 32px, and larger breaks 48px.
- Divider lines inside cards and menus run edge to edge; inset the content instead of the line.
- Filled lime action buttons and existing outlined buttons use a 1px muted olive `--button-border` (#8A916E); the shared Button primitive owns this rule. Quiet search, bell, conversation, edit and flag controls keep their existing presentation. Action buttons use the shared `--radius-control` (8px), including icon buttons. Avatars and status dots remain circular; message bubbles and photographs retain their own shapes. Messages use the envelope icon; post conversations use the speech bubble.
- Interactive controls retain at least 44px targets, visible keyboard focus, and reduced-motion alternatives.
- Dropdowns and selection lists inset their rounded hover/focus surfaces by `--menu-inset`; hover fills never meet the menu shell edge.
- Photographs use the shared 12px radius. Preserve full photographs in uncropped viewers and maintain aspect ratios.
- Card divider lines span the full inner width, edge to edge. Pad the content inside each section rather than insetting its divider.
- Horizontal dividers and navigation rules use the Dry Ink artwork through `--divider-mask` and `--divider-art-height`. Existing colors, widths, positions, and 1px layout borders remain owned by their feature styles. `rules.css` paints top/bottom separators; existing feed/header/navigation pseudo-elements use the same mask. Change the artwork token once to change the site-wide rule. Card and control outlines keep their original border geometry.
