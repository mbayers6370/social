# Music service marks

Original, unmodified black icons downloaded from the providers' official asset packs for links to their song pages. Marks belong to their respective owners.

- `apple-music.svg`: Apple Music 2020 icon pack, `Apple_Music_Icon_blk_sm_073120.svg`. [Apple Music identity guidelines and icon downloads](https://marketing.services.apple/apple-music-identity-guidelines).
- `spotify.svg`: Spotify's 2024 icon pack, `Primary_Logo_Black_RGB.svg`. [Spotify design guidelines and icon downloads](https://developer.spotify.com/documentation/design).

Use the supplied artwork with its original aspect ratio and sufficient clear space. The song links use 24px-tall assets on a light background, separated from text. These static files make no external requests and contain no scripts, external references, player or tracking code.

- `itunes-store.svg`: original `iTunes_Store_Small_Badge_RGB_012318.svg` from Apple’s [US/UK small-badge pack](https://www.apple.com/105/media/us/ipoditunes/itunes/2018/3a5387c5_1ebd_4993_9633_ff7264dc27bf/itunes-store-badges/us_uk.zip). See [iTunes identity guidelines](https://marketing.services.apple/itunes-identity-guidelines). Its source bytes and aspect ratio are preserved; CSS renders it smaller and lighter beneath the artist as requested. Display treatment requires review against current provider guidelines before release.
