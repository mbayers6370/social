Noto Sans Regular is bundled for portable account PDFs with embedded fonts.

Source: https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf
License: SIL Open Font License 1.1 (OFL.txt).
The website typography continues to use the existing Inter and Margin Hinge fonts.

Custom Margin Hinge and Margin Loose Mono font families, their specimen and their separate usage notes are under `margin/`. Hinge WOFF2 faces are loaded by `next/font/local`; the optional specimen stylesheet remains separate. Editable build sources are in `design/fonts/margin/`.
