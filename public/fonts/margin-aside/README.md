# Margin Aside

Original proportional lettering with rounded terminals and porous, worn-print ink in Light 300, Medium 500, and Bold 700. Each weight is provided as an installable TTF and matching WOFF2 webfont. `fonts.css` is optional and is not imported by the application.

Open `proof.html` for the Medium direction, or `specimen.html` to compare all three weights, change the reading size, and type your own sample. The font outlines include the ink wear; no CSS texture or simulated weight is needed.

This is development release 0.11, with 303 encoded characters per face. The manifest records the exact repertoire and file checksums. Italics and wider script coverage are not included. Editable source and build instructions are in `design/fonts/margin-aside/`.

Release 0.11 distinguishes the rounded capital O from an oval, dotted zero; adds facing comma-shaped curly quotes and separate straight quotes; provides distinct dash lengths; shortens capital I slabs; and includes text kerning and tighter punctuation spacing. Use Medium (500) for post body text, with `font-kerning: normal`.
